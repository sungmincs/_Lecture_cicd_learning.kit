# 10.10 검증: Terraform state를 GitLab에 맡기고 파이프라인으로 EKS 정리

## 확인 항목

- [ ] `eks-infra` 저장소에 `terraform.tfstate`와 `.terraform/`이 커밋되지 않았다
- [ ] Operate → Terraform states에 `eks` state가 있다
- [ ] 로컬 `terraform plan`과 CI plan job이 모두 `No changes.`다
- [ ] 로컬의 `terraform.tfstate.backup`을 지웠다
- [ ] apply와 destroy job은 manual이다
- [ ] destroy 전에 Argo CD Application, **모든** Ingress, LoadBalancer Service를 지웠고 로드밸런서가 0개였다
- [ ] destroy job이 `Destroy complete!`로 끝났다
- [ ] AWS에 EKS, EC2, VPC, NAT Gateway가 남지 않았다
- [ ] AWS Load Balancer Controller의 IAM 정책과 역할을 지웠다

## 확인 명령

```bash
git -C ~/workspace/eks-infra ls-files | grep -E "tfstate|\.terraform/" || echo "커밋된 state 없음"
aws eks list-clusters
aws ec2 describe-vpcs --filters Name=tag:Project,Values=cicd-learning-kit --query 'Vpcs[].VpcId'
```

## 참고

- KMS 키가 `PendingDeletion`으로 남는 것은 정상이다(과금 없음).
