## 체크리스트

- [ ] ⭐ **에이전트 이미지에 aws CLI + kubectl + argocd CLI 포함** (기본 `inbound-agent-docker`엔 없음). 빌드타임에 root로 `unzip`+aws CLI v2+kubectl+argocd 설치한 커스텀 이미지를 **레지스트리에 push**하고 파드 템플릿 이미지로 지정
- [ ] Jenkins Credentials: `dockerhub-credentials`, `github-token`, `aws-access-key-id`, `aws-secret-access-key`, (Part B) `argocd-admin-password`
- [ ] ⛔ **CI IAM 유저에 `eks:DescribeCluster` 정책 + EKS access entry 둘 다** (10.6 공통)
- [ ] ⛔ **deploy_manifest HTTPRoute → ALB Ingress** (10.6 공통)
- [ ] Part A: build → `update-kubeconfig` → `kubectl apply` → rollout 성공
- [ ] Part B: 이미지태그 push → `argocd app sync` → Synced/Healthy
- [ ] `kubectl get pods`에 worklog-backend `Running`

## 검증 메모 (실배포, 로컬 arm64 Vagrant)

- 2026-07-03 로컬 Jenkins(k8s 플러그인 동적 에이전트) → EKS로 Part A·B 모두 그린.
- 로컬 환경 특이사항(원인·해결):
  - **git HTTPS 인증서 검증 실패**: Debian git=GnuTLS라 GitHub Sectigo ECC 체인 검증 실패(curl/openssl은 성공). 에이전트 이미지 `ca-certificates` 최신화로 해결(임시 `git clone -c http.sslVerify=false` 우회 가능하나 배포용 아님). ch5~ch9 checkout에도 동일 영향.
  - **노드 시계 드리프트**: 호스트 절전 후 VM 시계가 느려지면 AWS `InvalidSignatureException: Signature expired`. 실행 전 `systemctl restart systemd-timesyncd`로 동기화.
  - **크로스아치 빌드 디스크 압박**: arm64 에이전트에서 `--platform linux/amd64` 빌드는 노드 `ephemeral-storage` eviction을 유발할 수 있음. 오래된 buildx 빌더/캐시 정리로 여유 확보.
  - **에이전트 노드 고정**: DNS/도커가 건강한 노드(cp-k8s)에 파드 템플릿 nodeSelector로 고정하면 `registry-1.docker.io i/o timeout`을 피함. 로컬 import 이미지는 스케줄된 노드에 없으면 ImagePullBackOff → 레지스트리 push가 정석.
