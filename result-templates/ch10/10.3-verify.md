# 10.3 AWS 환경 설정 — 예상 결과

## 상태 확인

### AWS CLI 설치 + 자격증명

```
$ aws --version
aws-cli/2.x.x Python/3.x.x Darwin/... source/arm64

$ aws sts get-caller-identity
{
    "UserId": "AIDA...",
    "Account": "<AWS_ACCOUNT_ID>",
    "Arn": "arn:aws:iam::<AWS_ACCOUNT_ID>:user/<사용자>"
}
```

### Terraform 설치 확인

```
$ terraform version
Terraform v1.x.x
on darwin_arm64
```

### 리전 설정 확인

```
$ aws configure get region
<aws_region>      # 리전 선택이 있는 기존 계정은 ap-northeast-2, 새 가입 방식(한국)은 ap-southeast-2

$ aws ec2 describe-availability-zones --query 'AvailabilityZones[].ZoneName' --output text
<aws_region>a  <aws_region>b  <aws_region>c
```

## 체크리스트

- [ ] AWS CLI v2 설치됨 (`aws --version`)
- [ ] `aws sts get-caller-identity`가 계정/ARN 반환 (자격증명 유효)
- [ ] 대상 IAM 사용자에 EKS·VPC·EC2·IAM 생성 권한 (실습은 AdministratorAccess 가정)
- [ ] Terraform 설치됨 (`terraform version`, 1.0 이상)
- [ ] 기본 리전이 내 계정 리전(10.3 단계 4)이고, 가용 영역 조회가 SCP에 거부되지 않는다
- [ ] (새 가입 방식) SCP는 배정 리전 밖, OIDC provider 생성, 무료 등급 밖 인스턴스를 막는다는 것을 안다

## 주의

- 계정 ID·이메일은 기록물에서 마스킹(`<AWS_ACCOUNT_ID>`)한다.
- 이후 10.4~10.10은 **비용이 발생**한다(EKS 컨트롤플레인 ~$0.10/hr + 노드 + NAT). 한 세션에서 이어서 진행하고, 10.10 마지막 단계에서 지운다.
