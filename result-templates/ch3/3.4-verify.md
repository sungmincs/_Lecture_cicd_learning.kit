# 3.4 Worklog 앱 K8s 배포 — 예상 결과

## 상태 확인

### Gateway에 할당된 LB EXTERNAL-IP

NGINX Gateway Fabric controller가 Gateway 객체마다 default ns에 자동 생성한 LoadBalancer Service:

```
[root@cp-k8s ~]# kubectl get gateway nginx-gateway -o wide
NAME            CLASS   ADDRESS        PROGRAMMED   AGE
nginx-gateway   nginx   192.168.1.XX   True         10m

[root@cp-k8s ~]# kubectl get svc nginx-gateway-nginx
NAME                  TYPE           CLUSTER-IP      EXTERNAL-IP    PORT(S)
nginx-gateway-nginx   LoadBalancer   10.xxx.xxx.xxx  192.168.1.XX   80:32XXX/TCP
```

> 💡 EXTERNAL-IP는 MetalLB IPAddressPool(192.168.1.11-99)에서 자동 할당. 보통 첫 사용 가능한 `.11`이 할당됨. vagrant up 직후 약 9~10분간 `<pending>`이 정상 (sleep& 백그라운드 적용 대기). 그 이후에도 `<pending>`이면 트러블슈팅 참조.

## 체크리스트

### 사전 환경
- [ ] ch3.3 완료 (Docker Hub에 `<user>/worklog-frontend-mock:buildtest1`, `<user>/worklog-backend:buildtest1`)
- [ ] cluster 4-node Ready (`kubectl get nodes`)
- [ ] MetalLB IPAddressPool 존재 (`kubectl get ipaddresspool -n metallb-system`)
- [ ] `kubectl get gateway nginx-gateway` PROGRAMMED=True + ADDRESS 할당 (`nginx-gateway-nginx` Service가 EXTERNAL-IP 받음)
- [ ] storage class `managed-nfs-storage`에 `(default)` 표시

### 배포
- [ ] 호스트 hosts 파일에 두 도메인 등록 (학습자 호스트 머신, EXTERNAL-IP 사용)
- [ ] 매니페스트 image 필드 수정 완료 (`<dockerhub_username>` + `worklog-frontend-mock`)
- [ ] `kubectl apply -f ./worklog_manifests` 정상 종료 (에러 없이)
- [ ] worklog-frontend, worklog-backend, worklog-mongodb 3개 Pod 모두 Running (READY 1/1)
- [ ] PVC `pvc-worklog-mongodb` Bound
- [ ] Gateway `nginx-gateway` (controller가 설치 시 만든 default ns Gateway) PROGRAMMED=True + ADDRESS 할당. 신규 Gateway 객체는 만들지 않음 — 두 HTTPRoute가 기존 `nginx-gateway`를 parent로 참조
- [ ] 두 HTTPRoute (frontend, backend) 표시 + 각 hostnames 매칭
- [ ] 호스트 브라우저에서 `http://worklog-frontend.myk8s.local` 접속 → UI 표시
- [ ] 호스트 브라우저에서 `http://worklog-backend.myk8s.local` 접속 → Swagger/API 표시
- [ ] UI에서 작업 추가 → 새로고침해도 데이터 유지 (MongoDB 영속화 확인)

## 이 단계 이후 아키텍처

```
[학습자 호스트]
  └── 브라우저
       │
       ↓ HTTP (hosts 파일: 192.168.1.XX → worklog-{frontend,backend}.myk8s.local)
       ↓
[Vagrant cluster: 4 nodes (cp + w1~w3)]
  └── MetalLB layer2 (IPAddressPool 192.168.1.11-99)
       └── nginx-gateway controller Service (EXTERNAL-IP 192.168.1.XX, LoadBalancer)
            └── Gateway nginx-gateway (controller 설치 시 생성, default ns, listener http:80)
                 ├── HTTPRoute worklog-frontend (hostname worklog-frontend.myk8s.local)
                 │     └── backend svc worklog-frontend (port 8080 → targetPort 5173)
                 │           └── pod worklog-frontend (image: <user>/worklog-frontend-mock:buildtest1)
                 │                 └── ENV VITE_API_URL=http://worklog-backend.default.svc.cluster.local:80
                 │
                 └── HTTPRoute worklog-backend (hostname worklog-backend.myk8s.local)
                       └── backend svc worklog-backend (port 80)
                             └── pod worklog-backend (image: <user>/worklog-backend:buildtest1)
                                   ├── readiness/liveness probe: GET /health
                                   ├── ENV MONGO_HOST=worklog-mongodb.default.svc.cluster.local
                                   └── (cluster DNS resolves) → svc worklog-mongodb (ClusterIP, 27017)
                                         └── pod worklog-mongodb (mongo:4.4.29-focal)
                                               └── PVC pvc-worklog-mongodb (1Gi, managed-nfs-storage)
                                                     └── NFS export from cp:/nfs_shared/dynamic-vol
```
