# 3.2 Worklog 앱 다운로드 및 로컬 실행 — 예상 결과

## 상태 확인

### Node.js + Yarn 설치 확인

```
[root@cp-k8s ~]# node --version
v20.x.x

[root@cp-k8s ~]# yarn --version
1.22.x   (또는 Yarn Berry 4.x)
```

### dev server 동작 확인 (control plane 노드 안)

```
[root@cp-k8s worklog-frontend-mock]# ss -tnlp | grep 5173
LISTEN 0  511  0.0.0.0:5173  0.0.0.0:*

[root@cp-k8s worklog-frontend-mock]# curl -sI http://localhost:5173 | head -3
HTTP/1.1 200 OK
Content-Type: text/html
```

### 호스트 브라우저 화면

`http://192.168.1.10:5173` 접속 시 Worklog 앱 UI가 표시되며, 작업 기록 목록·달력 등 mock 데이터로 채워진 화면을 볼 수 있다.

## 체크리스트

- [ ] Node.js 20.x 설치됨 (`node --version`)
- [ ] Yarn 설치됨 (`yarn --version`)
- [ ] `worklog-frontend-mock` fork 완료 (학습자 GitHub 계정에 표시)
- [ ] control plane 노드에 `/root/workspace/worklog-frontend-mock/` 존재
- [ ] `yarn install` 정상 종료 (peer dep 경고는 무해)
- [ ] `yarn dev --host 0.0.0.0` 실행 후 `Local`/`Network` URL 출력
- [ ] dev server가 `0.0.0.0:5173`에 listen 중 (`ss -tnlp | grep 5173`)
- [ ] 호스트 브라우저에서 `http://192.168.1.10:5173` 접속 → Worklog UI 표시
- [ ] mock 데이터(작업 기록 목록 등)가 화면에 보임

## 이 단계 이후 아키텍처

```
[학습자 호스트]
  └── 브라우저 (http://192.168.1.10:5173)
       │
       ↓  private network
[Vagrant VM: cp-k8s (192.168.1.10)]
  ├── root 사용자 작업 디렉토리
  │   ├── /root/_Lecture_cicd_learning.kit  (controlplane_node.sh 자동 clone)
  │   └── /root/workspace/worklog-frontend-mock  (학습자 fork clone)
  ├── Vite dev server (yarn dev, port 5173)
  │    └── React app
  │         └── MSW (Mock Service Worker)
  │              └── mock 응답 반환
  └── (참고) K8s control plane은 가동 중이나 본 챕터에선 미사용
```

K8s 클러스터는 ch2에서 구축했지만 ch3.2에서는 사용하지 않는다. ch3.4에서 본격 활용한다.
