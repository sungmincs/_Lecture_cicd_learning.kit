### 단계 4: argocd CLI 설치 `[학습자 직접]`

컨트롤 플레인 노드에 설치한다. CPU 종류에 맞는 바이너리를 서버와 같은 버전(v3.4.3)으로 받는다.

```bash
ARCH=$(uname -m); [ "$ARCH" = "aarch64" ] && BIN=argocd-linux-arm64 || BIN=argocd-linux-amd64
curl -sSL -o /usr/local/bin/argocd https://github.com/argoproj/argo-cd/releases/download/v3.4.3/$BIN
chmod +x /usr/local/bin/argocd
argocd version --client   # v3.4.3
```

### 단계 5: argocd CLI 로그인 `[학습자 직접]`

노드에서는 `argocd.myk8s.local`이라는 이름을 모른다(hosts 파일은 호스트에만 고쳤다). 클러스터 안의 Service 주소로 로그인한다.

```bash
ARGOCD_IP=$(kubectl get svc argocd-server -n argocd -o jsonpath='{.spec.clusterIP}')
argocd login $ARGOCD_IP --username admin --plaintext
# Password: 프롬프트에 6.3 단계 4의 초기 비밀번호를 붙여 넣는다(화면에 보이지 않는다)
argocd account get-user-info      # Logged In: true
```

`--password` 옵션으로 넘기지 않는다. 명령줄에 쓰면 셸 기록에 남는다.

> ⚠️ **`--insecure`가 아닌 `--plaintext`** 를 사용해야 합니다.
> - `--insecure`: 인증서 검증을 건너뛰는 옵션이다. 이 서버는 TLS가 없어서 `server is not configured with TLS. Proceed (y/n)?`를 묻고 멈춘다
> - `--plaintext`: HTTP 평문 연결 사용 (이 강의 환경에 맞는 옵션)
