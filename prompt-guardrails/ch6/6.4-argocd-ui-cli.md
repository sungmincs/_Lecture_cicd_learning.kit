### 단계 4: argocd CLI 설치 `[학습자 직접]`

```bash
# macOS
brew install argocd

# Linux
curl -sSL -o argocd-linux-amd64 \
  https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
chmod +x argocd-linux-amd64
sudo mv argocd-linux-amd64 /usr/local/bin/argocd
```

### 단계 5: argocd CLI 로그인 `[학습자 직접]`

**호스트 머신(macOS)에서 접속:**
```bash
argocd login argocd.myk8s.local \
  --username admin \
  --password <초기-비밀번호> \
  --plaintext
```

**control plane 노드(ssh 접속 상태)에서 접속:**
```bash
# argocd-server ClusterIP 먼저 확인
kubectl get svc argocd-server -n argocd

argocd login <ClusterIP> \
  --username admin \
  --password <초기-비밀번호> \
  --plaintext
```

> ⚠️ **`--insecure`가 아닌 `--plaintext`** 를 사용해야 합니다.
> - `--insecure`: HTTPS 연결에서 인증서 검증 건너뜀 (HTTP에는 효과 없음)
> - `--plaintext`: HTTP 평문 연결 사용 (이 강의 환경에 맞는 옵션)

### 단계 6: CLI 기본 명령 탐색 `[AI 프롬프트]`
