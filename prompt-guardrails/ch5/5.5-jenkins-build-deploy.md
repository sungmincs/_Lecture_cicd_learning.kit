## 실행 지침

### 단계 1: Jenkins Credentials 등록 `[학습자 직접]`

Jenkins → Dashboard → Credentials → System → Global → Add Credentials

| 종류 | ID | 값 |
|---|---|---|
| Username with password | `dockerhub-credentials` | Docker Hub username + Access Token |
| Secret file | `cp-k8s-context` | kubeconfig 파일 |

- ⛔ AI가 하지 말 것: Jenkins Credentials를 직접 등록하지 말 것
