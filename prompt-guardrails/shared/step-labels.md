# 실습 단계 라벨 기준

가드레일의 `## 실행 지침` 단계에 붙이는 라벨과 쓰는 방식이다. 새 절을 쓰거나 기존 절을 고칠 때 이 기준을 따른다(2026-10-09 정함).

## 라벨은 둘

| 라벨 | 뜻 | 단계 안에 두는 것 |
|---|---|---|
| `[학습자 직접]` | 학습자가 손으로 한다 | 명령 블록, 또는 웹 조작 절차 |
| `[AI 프롬프트]` | 학습자가 AI에게 시킨다 | 프롬프트 인용문(`> "..."`)과 정답 파일 경로 |

- 단계마다 라벨은 하나다. 한 단계에 두 성격이 섞이면 단계를 나눈다.
- `[AI 프롬프트]` 단계에는 학습자가 칠 명령 블록을 두지 않는다. 그 명령은 `[학습자 직접]` 단계로 뺀다.
- `[학습자 직접]` 단계에는 명령 블록이 있어야 한다. "push한다"처럼 문장으로만 적지 않는다.
- 명령 블록에 `[root@cp-k8s ~]#` 같은 프롬프트 접두를 붙이지 않는다. 그대로 붙여 넣어 실행되는 형태로 둔다.

## 위치는 노드가 기본

실습은 컨트롤 플레인 노드에서 한다. 그래서 위치는 적지 않고 예외만 적는다.

| 표기 | 언제 |
|---|---|
| `[학습자 직접 · 웹]` | 브라우저와 UI 조작(GitHub, Docker Hub, Jenkins, Argo CD, GitLab, AWS 콘솔, Slack) |
| `[학습자 직접 · 호스트]` | 호스트 PC에서 치는 것(ssh 접속, hosts 파일, Claude Code 실행) |

AI는 호스트의 Claude Code에서 ssh로 노드의 파일을 읽고 쓴다. 이 전제는 AGENTS.md에 있으므로 단계마다 적지 않는다. 다만 AI가 노드 파일을 고치는 단계는 프롬프트에 경로를 적는다(예: `/root/workspace/worklog-backend/`).

## 행동은 단계에만

- 사전 조건에는 상태만 적는다("ch6.5 완료", "Docker Hub에 이미지가 있음"). 명령이 필요하면 단계로 올린다.
- 체크리스트, 주의사항, 트러블슈팅에 들어 있는 실제 행동(`argocd app set`, 워크플로 끄기, `uv lock`)은 단계로 올린다. 주의사항은 "하지 말 것"과 "해도 됨"만 둔다.
- 주의사항의 "AI가 하지 말 것"이 본문 단계와 어긋나면 본문에 맞춘다.

## 용어

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 학습자 | 독자, 사용자 |
| AI | 클로드, Claude(가드레일 본문에서. 시연 화면과 강의 제목은 Claude Code) |
| 컨트롤 플레인 노드 | cp, cp 노드, control plane 노드 |
| 호스트 | 로컬, 내 컴퓨터, 학습자 PC |

호스트 이름 `cp-k8s`와 `ssh root@192.168.1.10`은 실제 값이라 그대로 쓴다. 프롬프트 인용문은 "~해줘"체로 맞춘다.
