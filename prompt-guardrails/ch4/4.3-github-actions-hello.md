# 4.3 GitHub Actions 첫 파이프라인 (Hello World)

> **학습자 진입 방식**:
> - `[학습자 직접]`: git push, GitHub UI 클릭
> - `[AI 프롬프트]`: .yaml 파일 작성, 디렉토리 생성

## 사전 조건

- GitHub 계정 보유
- worklog-frontend-mock 또는 worklog-backend 저장소가 본인 계정에 fork되어 있음
- 로컬 또는 control plane에서 git clone 된 상태

## 실행 지침

### 단계 1: 워크플로우 디렉토리 생성 `[AI 프롬프트]`

> "GitHub Actions 워크플로우 디렉토리 만들어줘."

AI가 `.github/workflows/` 디렉토리를 생성합니다.

### 단계 2: Hello World 워크플로우 작성 `[AI 프롬프트]`

> "Hello World GitHub Actions 워크플로우 만들어줘."

AI가 학습자와 함께 처음부터 워크플로우를 작성합니다.

✅ 정답 파일 (완성 후 비교): `ch4/4.3/1.hello-actions_basic.yaml`

### 단계 3: git push `[학습자 직접]`

```bash
git add .github/
git commit -m "add: hello world workflow"
git push
```

### 단계 4: GitHub Actions UI에서 실행 확인 `[학습자 직접]`

- GitHub 웹 → 저장소 → Actions 탭
- 워크플로우 실행 결과 확인

### 단계 5: Variables 워크플로우 `[AI 프롬프트]`

> "GitHub Context와 Variables를 쓰는 워크플로우도 만들어줘."

✅ 정답 파일 (완성 후 비교): `ch4/4.3/2.hello-actions_variables.yaml`

## 주의사항

- ⛔ AI가 하지 말 것: git push를 대신 실행하지 말 것 — 학습자가 직접 push해야 Actions가 트리거됨을 체감
- ⛔ AI가 하지 말 것: GitHub UI 조작을 대신하지 말 것
- ✅ AI가 해도 됨: `.github/workflows/` 디렉토리 생성 및 yaml 파일 작성
- ✅ AI가 해도 됨: 워크플로우 실행 결과 해석 및 에러 설명
- ⛔ AI가 하지 말아야 할 것: 전체 yaml 파일 내용을 한 번에 제공하지 말 것 — 수강생이 직접 타이핑하는 것이 학습에 도움됨. 단계별로 안내할 것
- ⛔ AI가 하지 말아야 할 것: Step 2를 건너뛰고 바로 상세 버전(Step 5)으로 가지 말 것 — 기본 Hello World를 먼저 경험해야 함

## 검증 중 발견된 사항 (강의자 참고)

- **Node.js 20 deprecation 경고**: `actions/checkout@v4`, `astral-sh/setup-uv@v5` 실행 시 GitHub Actions 로그에 다음 경고가 출력됨:
  ```
  Node.js 20 actions are deprecated. Actions will be forced to run with Node.js 24 by default starting <날짜>.
  ```
  → 현재 기능 동작에 영향 없음. 교재/슬라이드에서 구체적인 날짜를 특정하지 말 것 — 날짜가 변경될 수 있음 (실제로 "June 2nd"에서 "June 16th"로 2주 연장된 사례 있음). "2026년 중반" 또는 "곧 강제 전환 예정" 등 추상적 표현 사용.
