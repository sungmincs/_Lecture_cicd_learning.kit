- ✅ AI가 해도 됨: `.gitlab-ci.yml` 작성 + GitOps 흐름 설명
- ✅ AI가 해도 됨: workflow.rules와 YAML anchor 결합 설명

- ⚠️ `$CI_COMMIT_BRANCH`는 태그 빌드에서 비어있음 — `$CI_COMMIT_TAG`로 분기하여 `BRANCH=main`으로 설정

## 검증 중 발견된 이슈 (강의자 참고)

- **태그 빌드에서 deploy job `git push` 실패 — `CI_COMMIT_BRANCH` 빈 값 버그**: v* 태그 빌드 시 `$CI_COMMIT_BRANCH`가 비어있어 `git push origin HEAD:` (빈 refspec)이 실행되어 `fatal: invalid refspec 'HEAD:'` 오류 발생.
  - 증상: `fatal: invalid refspec 'HEAD:'`, `You are not currently on a branch.`
  - 원인: GitLab CI에서 태그 트리거 시 `CI_COMMIT_BRANCH`는 빈 문자열, 태그명은 `CI_COMMIT_TAG`에만 설정됨
  - 해결: deploy job의 push 전 BRANCH 결정 로직을 명시적으로 처리
  - 참조 파일 `ch8/8.8/1.full-cicd-pipeline.yml`에 이미 반영됨
  - 수정된 코드:
    ```bash
    if [ -n "$CI_COMMIT_TAG" ]; then
      BRANCH="main"
    else
      BRANCH="$CI_COMMIT_BRANCH"
    fi
    git pull --rebase origin $BRANCH || true
    git push origin HEAD:$BRANCH
    ```
