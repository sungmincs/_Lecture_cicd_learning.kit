# 2.4 클러스터 구성 (강의자/검증자 전용)

> **이 파일은 Internal 전용입니다.** 자동화 검증 런 또는 장시간 실습 환경 구성 시 참고.

## 슬립 방지 (caffeinate)

검증 런 또는 장시간 실습 중 macOS가 슬립에 들어가면 VirtualBox가 VM을 자동 일시정지합니다.
`vagrant up` 전에 caffeinate를 VBoxHeadless 프로세스에 걸어두면 VM이 살아있는 동안 슬립이 방지됩니다.

```bash
# vagrant up 완료 후 VBoxHeadless PID에 연결
caffeinate -diw $(pgrep VBoxHeadless | head -1) &
```

VM 종료 시 caffeinate도 자동 종료되므로 별도 kill 불필요.
