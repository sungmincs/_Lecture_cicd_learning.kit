# 2.4 VirtualBox, Vagrant, Tabby 설치 (arm64)

> **학습자 진입 방식**:
> - `[학습자 직접 · 호스트]`: 강의 저장소 받기, 설치 명령 실행, 설정 파일 복사
> - `[AI 프롬프트]`: 없음. AI는 설치 오류를 해석하는 역할만 한다
>
> 라벨 읽는 법은 `prompt-guardrails/shared/step-labels.md`. 이 절은 아직 AI 에이전트를 설치하기 전이라 모든 단계를 학습자가 직접 한다.
> Apple Silicon 맥(M1 이후)은 이 절을 따른다. x86-64(amd64) PC와 인텔 맥은 2.3을 따른다.

## 실행 지침

### 단계 0: 강의 저장소 받기 `[학습자 직접 · 호스트]`

이 절의 설치 파일과 Vagrantfile이 강의 저장소 안에 있다. 홈 디렉터리에 받는다.
Git이 없으면 먼저 설치한다(`xcode-select --install` 또는 `brew install git`).

```bash
git --version                       # 버전이 나오면 Git은 이미 있다
cd ~
git clone https://github.com/sungmincs/_Lecture_cicd_learning.kit.git
cd _Lecture_cicd_learning.kit/ch2/2.4
```

아래 단계의 `./virtualbox-v7.1.10/`, `./tabby-v1.0.207/` 같은 상대 경로는 이 폴더 기준이다.
2.12에서 Claude Code를 띄우는 곳도 이 저장소다.

### 단계 1: VirtualBox 7.1.10 설치 `[학습자 직접 · 호스트]`

```bash
brew install --cask ./virtualbox-v7.1.10/virtualbox.rb
```

- 참고: 로컬 .rb 파일을 사용하여 버전을 고정함
- 기대 결과: VirtualBox 7.1.10이 설치됨

### 단계 2: Vagrant 2.4.7 설치 `[학습자 직접 · 호스트]`

```bash
brew install --cask ./vagrant-v2.4.7/vagrant.rb
```

- 예전에 VMware용 플러그인을 깔았다면 지운다(선택): `vagrant plugin uninstall vagrant-vmware-desktop`
- 기대 결과: Vagrant 2.4.7이 설치됨

### 단계 3: Tabby 1.0.207 설치 및 설정 파일 복사 `[학습자 직접 · 호스트]`

```bash
brew install --cask ./tabby-v1.0.207/tabby.rb
cp ./tabby-v1.0.207/config.yaml ~/Library/Application\ Support/tabby/
```

- 기대 결과: Tabby가 설치되고 사전 구성된 config.yaml(cp-k8s, w1~w3 프로필)이 적용됨
