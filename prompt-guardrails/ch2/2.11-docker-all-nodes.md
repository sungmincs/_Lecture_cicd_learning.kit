# 2.11 Docker를 모든 노드에 설치

> **학습자 진입 방식**:
> - `[학습자 직접 · 호스트]`: 컨트롤 플레인 노드에 ssh 접속
> - `[학습자 직접]`: 설치 스크립트 실행, 확인
> - `[AI 프롬프트]`: 없음. 아직 AI 에이전트를 설치하기 전이다(2.12)
>
> 이 Docker는 3.5에서 이미지를 빌드할 때, 그리고 5.6부터 Jenkins 에이전트가 노드의 `docker.sock`으로 이미지를 빌드할 때 쓴다.
> 클러스터 자체는 containerd로 돌기 때문에 쿠버네티스에는 필요 없고, CI 쪽에 필요하다.

## 범위
### 이 단계에서 다루는 것
- K8s 클러스터의 **모든 노드**(컨트롤 플레인 노드 + 워커 3대)에 Docker 설치
- 컨트롤 플레인 노드는 로컬 실행, 워커는 sshpass로 원격 설치

### 이 단계에서 다루지 않는 것
- Docker 이미지 빌드와 push (ch3/3.5에서 다룸)
- Docker 없이 로컬 실행 (ch3/3.3에서 다룸)

## 사전 조건
- ch2/2.3 또는 ch2/2.4 완료 (K8s 클러스터 구축 완료)
- 컨트롤 플레인 노드에 root로 SSH 접속 가능 (`controlplane_node.sh` 안에서 `/root/_Lecture_cicd_learning.kit`이 자동 clone됨)
- 컨트롤 플레인 노드 → 워커 노드 SSH 접속 가능 (vagrant box 기본 설정)

## 실행 지침

### 단계 1: 컨트롤 플레인 노드에 root로 접속 `[학습자 직접 · 호스트]`

```bash
ssh root@192.168.1.10
# 비밀번호: vagrant
```

### 단계 2: 본 디렉터리로 이동 `[학습자 직접]`

```bash
cd /root/_Lecture_cicd_learning.kit/ch2/2.11
```

### 단계 3: 설치 스크립트 실행 `[학습자 직접]`

```bash
bash docker_all_nodes_installer.sh
```

동작:
- 컨트롤 플레인 노드(local)에 Docker 설치
- sshpass로 워커 노드 3대(192.168.1.101~103)에 Docker 설치

기대 결과: 4개 노드 모두에 Docker 설치 완료

## 검증
| 단계 | 검증 방법 | 기대 결과 |
|------|----------|----------|
| Docker 설치 | 각 노드(cp-k8s, w1~w3)에서 `docker version` | Docker 버전 정보 출력 |
| Docker 동작 | 각 노드에서 `docker ps` | 권한 오류 없이 실행 |

## 주의사항
- ⛔ 반드시 컨트롤 플레인 노드(`cp-k8s`)에 root로 접속 후 실행
- ⛔ `./install_docker.sh` 파일이 같은 디렉토리(ch2/2.11)에 존재해야 함
- ✅ 스크립트가 컨트롤 플레인 노드(local) + 워커 노드 3대(w1~w3) 총 4개 노드를 대상으로 순차 실행
- ✅ root 사용자라 별도 sudo·chmod 666 docker.sock 불필요
